# 감독 장소 목록

> 이 프로젝트에서 반복해 쓰는 위치(파일·폴더 경로, 깃 저장소·이슈, 지라 사이트·프로젝트 키·보드, 문서 URL, 자주 쓰는 명령)의 원본이다. 감독이 "그 파일 옮겨", "그 깃 이슈 가져와", "지라 업데이트해"처럼 위치가 빠진 요청을 받으면, po가 요청 속 표현으로 이 파일을 grep해 걸린 줄만 읽고 실제 위치로 바꾼다. 감독은 이 파일을 읽지 않고, 찾은 실제 위치를 `[감독 지시]`·위임 프롬프트에 넣는다. 작업 세션과 작업을 맡은 하위 에이전트는 이 파일을 읽지 않는다 (읽는 것은 감독 롤 po·pm·tpm뿐이고 범위는 `war-room-commander` 스킬 6절).
>
> - 쓰기: 감독 롤 pm(`commander/roles/pm.md`)만 쓴다. 사용자가 확인한 위치만 적는다. 추측한 값은 적지 않는다.
> - 못 찾거나 여러 줄이 걸리면 감독이 사용자에게 묻고, 답을 받으면 pm이 적는다.
> - 낡은 위치(경로 없음·접근 실패)는 tpm이나 작업 보고로 알게 되면 감독이 사용자에게 확인하고, 확인받은 뒤 pm이 고친다. 고친 줄은 `확인한 날`을 바꾼다.
> - 토큰·비밀번호·인증 정보 같은 비밀은 적지 않는다. 위치와 식별자만 적는다.
> - 줄 형식: `이름(부르는 말) · 종류 · 위치 · 쓰는 때 · 확인한 날`. 부르는 말은 사용자가 실제로 쓰는 표현을 쉼표로 나열한다 (grep에 걸리게). 한 칸 안에 여러 값(사이트·키·보드)이 있으면 쉼표로 잇고 `·`는 칸 구분에만 쓴다.
