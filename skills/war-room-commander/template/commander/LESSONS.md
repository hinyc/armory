# 감독 시행착오

> 감독 쪽 교훈(감독·감독 롤의 판단 실수와 막힌 일, 같은 이유로 두 번 보완 지시한 일, 연결 워크트리 작업 세션 보고의 `겪은 문제` 중 다음 지시에 넣어야 할 것)의 원본이다. 감독 롤 pm(`commander/roles/pm.md`)만 쓴다. 새 항목은 위에 추가한다. 반영 후보는 감독이 사용자에게 보여주고, 승인받은 것만 감독이 승인 줄을 넣어 pm에 맡기면 pm이 반영처에 쓴다. 반영했거나 더는 맞지 않는 항목은 archive로 옮긴다 (`war-room-commander` 스킬 6절). 작업 세션 매니저의 `war-room/LESSONS.md`와 다른 파일이다.
