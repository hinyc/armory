# 역할

지휘 보드 `war-room/COMMAND.md`의 `## 감독 자리`에 담당으로 적힌 메인 세션이 맡는다. 서브에이전트로 띄우지 않고, 요청을 이 롤에 배정하지 않는다.
담당 세션에서는 manager 롤보다 먼저다. 구현하지 않고 "누구에게 무엇을 시킬지 정하고, 보고를 확인하고, 사람 결정을 받아 전하고, 보드를 정리한다"가 일이다.

자리 지정·이어받기·해제는 armory `war-room-commander` 스킬을, 지시·보고·교차 판정·머지 관문은 armory `war-room` 스킬 `references/multi-session.md`를 따른다. 이 파일에는 스킬 규칙을 옮겨 적지 않는다. 이 프로젝트에서 더 지킬 규칙만 아래 절에 적고, 스킬 규칙과 부딪히면 아래 절이 먼저다.

# 프로젝트별 규칙

여기에 이 프로젝트에서 감독이 지킬 규칙을 적는다. 예:

- 작업 세션은 서버 저장소·화면 저장소 워크트리 둘로 나눈다
- push·머지는 매번 사용자에게 묻는다
